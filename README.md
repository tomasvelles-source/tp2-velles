# Trabajo Práctico 2 – Programación Orientada a Datos (Individual)
## Reporte operativo de movimientos de Ecobici

- **Autor:** Tomás Velles Aguirre (`tomasvelles@gmail.com`)
- **Asignatura:** Programación Orientada a Datos – Licenciatura en Ciencia de Datos (UCA, 2026)
- **Modalidad:** Individual (Apéndice A – Opción 7)

## Objetivo del proyecto

Desarrollar una aplicación en Python que permita leer registros de viajes de Ecobici desde archivos CSV y JSON, validar fechas e identificadores, filtrar por período y calcular el balance operativo (salidas, llegadas y balance neto) de cada estación.

## Estructura inicial

- `src/`: módulos de código fuente
- `tests/`: pruebas unitarias con `unittest`
- `data/`: archivos de datos de entrada (`.csv` y `.json`)
- `outputs/`: reportes generados por el programa
